## 프로젝트 개요

라이프스타일 스포츠 브랜드 **아키클래식**의 시장 경쟁력과 트렌드 동조성을 진단하는 실시간 데이터 모니터링 프로젝트입니다.
네이버 데이터랩 검색 트렌드 및 블로그·뉴스·카페 언급 데이터를 기반으로,
브랜드의 검색 점유율·성장성·시장 포지셔닝을 자동으로 진단하고 분석 소견을 도출하는 인터랙티브 대시보드를 구현했습니다.

- **데이터 타임라인**: 2023년 1월 1일 ~ 현재(주간 자동갱신 후 월간 집계)
- **데이터 파이프라인**: Supabase DB ➔ Pandas 전처리/통계 보정 ➔ Streamlit UI 갱신(월간 갱신)

## 주요 분석 결과

| 지표 | 수치 | 해석 | 
|---|---|---|
| 장기 성장률(데이터 초기 6개월 vs 최근 6개월) | **+18%** | 23년 상반기(1~6월) 대비 최근 6개월 평균 기준, 메이저 정체 속 독보적 성장 |
| 최근 모멘텀(3개월 평활 YoY) | **+3.4%** | 전년 대형 캠페인 기저효과 속 순항 입증 |
| 니치 마켓 검색 점유율(SoS) | **85.4%** | 동급 DTC 마켓 내 압도적 시장 지배력 |
| GAP(SoS−SoV) | **+36%p** | 광고 노출 대비 소비자의 자발적 검색 전환 정도 우위 |

### 핵심 인사이트
- **니치 마켓 독점**: 동급 니치 마켓 내에서 85.4%의 압도적 검색 점유율을 기록하며 시장 지배력 확보
- **성장 엔진 검증**: 워킹·여행화 수요 침체(−46%, −49%) 속, 아키클래식이 베팅한 '발 건강(기능성/통증케어)' 수요만 유일하게 성장(+26%)중임을 포착, 브랜드의 장기 성장 곡선이 트렌드 동인과 일치함
- **메이저 체급 비교**: 경쟁 메이저 브랜드의 검색 수요가 정체인 반면, 아키클래식은 +18% 구조적 성장을 기록
- **전략 시사점**: 연간 계절성 지수 분석을 통해 검색 수요 기반 비수기(8월, 지수 57) 방어 전략 도출

## 분석 방법론

- **성장 지수 vs SoS 분리**: '자기 기간 평균(=100)'을 기준으로 정규화한 추세선(방향성 지표)과 실제 시장 파이 크기를 뜻하는 검색 점유율(SoS, % 지표)의 개념을 분리하여, 서로 다른 축 간의 Raw 데이터 단순 비교 차단
- **SoS−SoV GAP**: 검색 점유 대비 소셜 언급 점유 차이 — 자발적 수요 vs 광고 효율 진단(수집 채널 간 공통 수집 기간의 게시글 수만 카운트하며, 날짜 정보가 매칭되지 않는 '카페' 및 '영상(유튜브)' 채널 누락 한계점을 명시하여, 절대적인 수치 비교 대신 부호(+/−)의 방향성 중심 진단)
- **장기 성장률**: 최초 6개월 대비 최근 6개월 평균 검색량 변화율
- **3개월 평활 YoY**: 단일월 노이즈·기저효과 보정하여, 계절성을 자동 통제하고 단기 모멘텀을 객관적으로 진단하는 지표
- **완료월 컷오프**: 주간 데이터를 월간 단위로 리샘플링할 때, 수집이 진행 중인 '당월' 데이터는 통계 왜곡을 막기 위해 자동 제외
